## 二、保留核心功能模块（src/main 44 目录）

### 推理 / 模型
- `model-manager` — node-llama-cpp CPU 推理兜底
- `model-registry` — 模型长效注册表（卡片增删/默认/启动/待命）
- `tandem-manager` — llama-server 多模型联动引擎（GPU 主引擎）
- `runtime` — 硬件探测 + 运行参数自适应（显存分级）
- `inference` — 推理执行（CPU 引擎）
- `scheduler` — 调度系统（模型重排 + 云端补救 + 单模型常驻换载）
- `llm` — LLM Provider 注册表（本地 GPU / 云端 API）
- `local-ai-scanner` — 本地 AI 能力探测

### Agent 框架
- `agent` — 智能体操作系统（38 预设 + 组队 + ReAct + 工具注册 + 软件工具组）

### 桌面自动化
- `automation` — 桌面自动化
- `desktop-automation` — Python 桥接
- `ui-automation` — UIA 主力通路 + 视觉兜底/质检
- `uia` — UIA 定位层（零显存首选）
- `visual-agent` — 视觉五层引擎
- `dynamic-operation` — 动态操作
- `software-library` — 本机软件库（名称/类别匹配 + 版本/路径）

### 语音
- `tts` — Edge TTS + Piper 双引擎
- `voice-engine` — 语音引擎总装（VAD/降噪/声纹）
- `wake` — 语音唤醒
- `floating-ball` — 悬浮球 + 语音交互球

### 联网 / 搜索 / 知识
- `browser` — 内置浏览器多标签
- `search` — 联网搜索（web_search）
- `fulltext-search` — 本机文件全文检索（Whoosh 索引）
- `rag` — 检索增强（nomic-embed 向量库 + 来源透传）
- `knowledge-graph` — 知识图谱

### 记忆 / 上下文
- `context-manager` — 上下文管理 / 长期记忆
- `context-window` — 上下文压缩
- `personalization` — 个性化
- `persona-loader` — 人设加载（resources/personas canonical 主源）

### 系统 / 安全 / 运维
- `ipc` — 全部 IPC 处理器
- `register` — IPC 注册中心
- `secure` — 加密
- `self-modify` — 自我改造（白名单 + 开关）
- `skill-pack` — 插件打包
- `permission` — 权限
- `backup` — 备份
- `cloud-quota` — 云端配额（耗尽降级）
- `health-check` — 健康检查
- `ppt-flow` — PPT 生成流程
- `external-ai` — 外部 AI 接入
- `mcp` — MCP 协议
- `mobile-channel` — 手机通道
- `device` — 设备协同
- `task-router` — 任务路由
- `utils` — 工具函数
